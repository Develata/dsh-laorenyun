## 实现归属

- `archive/registry.ts`：原生 Workspace 成员关系与默认档案映射；数据原地迁移。
- `storage/database.ts`、`worker.ts`：一 worker、多档案连接；全局有界信箱，预定义领域操作。
- Host 请求与后台任务固定档案，Session 校验以原生成员/父支线身份为准。跨档案 Source ID 不可见。
- `client/shell.tsx`：品牌、人物档案、采访记录、主导航、辅助右栏；不替换 DSH shell。
- `client/journey.tsx`：纵向正常滚动、实测弧长、真实区间子路径、密度聚合、漂流湾、显式列表模式。
- `client/memory-detail.tsx`、`biography.tsx`：独立详情/阅读面；更正仍为新证言。
- `derived/narrative.ts`：事实宇宙与计划/写作/审校契约；`service.ts` 复用原派生生命周期。旧 generation 可读，新生成使用 narrative-v2。
- `speech/settings.ts`：复用 DSH settings secret 字段；`.env` 是基础配置，Web 用户层可覆盖。不存在第二个凭据数据库。

## RC3：当前支持与历史出处分离

RC2 证据保持不变。RC3 修正同节点更正的派生投影：`sourceRefs/testimony` 仅指当前叙事支持；可选 `historyRefs` 记录包含继承证言的历史合集。使用 resolved Conflict 的旧/新 revision 边界排除继承来源，不按年份或正文匹配。不同节点的冲突选择保留被选一侧及澄清来源；open Conflict 省略策略不变。完整历史仍在固定 Manifest、图修订和 memories.json。旧生成结果不被静默重写，需要显式重新生成。
