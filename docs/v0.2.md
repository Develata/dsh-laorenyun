# v0.2 实现与验收记录

状态：进行中，不能据此标记 RC 通过。产品决定见应用仓库 ADR 0018 与 v0.2-redesign。历史 v0.1/Phase 证据不改写；Phase 2 R2/R3 仍 pending。

## 实现归属

- `archive/registry.ts`：原生 Workspace 成员关系与默认档案映射；数据原地迁移。
- `storage/database.ts`、`worker.ts`：一 worker、多档案连接；全局有界信箱，预定义领域操作。
- Host 请求与后台任务固定档案，Session 校验以原生成员/父支线身份为准。跨档案 Source ID 不可见。
- `client/shell.tsx`：品牌、人物档案、采访记录、主导航、辅助右栏；不替换 DSH shell。
- `client/journey.tsx`：纵向正常滚动、实测弧长、真实区间子路径、密度聚合、漂流湾、显式列表模式。
- `client/memory-detail.tsx`、`biography.tsx`：独立详情/阅读面；更正仍为新证言。
- `derived/narrative.ts`：事实宇宙与计划/写作/审校契约；`service.ts` 复用原派生生命周期。旧 generation 可读，新生成使用 narrative-v2。
- `speech/settings.ts`：复用 DSH settings secret 字段；`.env` 是基础配置，Web 用户层可覆盖。不存在第二个凭据数据库。

## RC2 原子事实验证（2026-09-19，验收进行中）

原失败记录只读检查：6个failed生成、15份reviews。实际类别包括身份重绑定、家人归属漏检/误拒、无依据“那时/上学时”时间关联、持续记忆等心理补写、标题全称范围误读、旧年份与明确纠正年份被再次当作未解决冲突。coverage此前仅查factRefs集合，不能证明正文实际表达事实。不是单纯JSON格式问题。

派生FactAtom新增sourceMode/narrativePolicy/temporalPolicy/conflictPolicy。未知时间本人事实仍required；明确家人素材requires_attribution；图没有传主身份绑定的家人关系词optional_ambiguous；open Conflict excluded。计划每条必须使用或合法省略；closed enum拒绝任意丢弃。已解决记录的旧证言留在manifest，不进入当前Writer/Verifier材料作为活动备选。

段落写作、原子span/claim/kind/status审校、段落内ID和语义覆盖检查；显式年份/月日/年龄检查；正文中实际存在、对应fact的attribution surface检查。一次语义修复只改失败段落，已成功段落保留；可省略段落持续失败记录insufficient_context，空章省略。标题独立验证/一次标题修复。不存在keySentence拼接回退。总生成截止仍5分钟，单模型调用60秒含一次格式修复，共享2并发/32等待；新增总段落上限40。

原子审校记录属于显式派生结果，不是隐藏思维过程；diagnostics只存章节、段号、类别、状态、factRefs和固定reasonCode，默认日志不输出正文。合成fixture A-I与显式空卷seed CLI仅用于手动验收，普通启动不执行。无新依赖、无图迁移。

56项离线测试通过；真实固定SHA Docker三次稳定性验收由应用记录，不提前宣布通过。

### RC2 标题失败隔离补充

固定 `b38de56` Docker 复测首本仍失败（87.610s）：正文局部修复已通过，章名把“出生于安徽村子”扩展为“在安徽村子长大”，一次标题修复又写成当地童年。原子审校正确拒绝，没有发布。根因是标题修复把叙事 brief 当成了事实提示。

标题修复现在只接收标题允许的 FactAtoms 和拒绝报告，不接收 brief；一次修复仍不通过时，使用本章已发布候选正文中独立审校通过的短本人事实片段作标题。没有安全短片段时仅使用章序号。此兜底只影响标题，不拼接 keySentence、不重写正文、不增加事实。后续三次固定镜像验收以应用库 RC2 证据为准，不能以这次失败宣称通过。

`9db85c4` 三本浏览器生成虽可发布，人工审读第二本仍发现标题“我是在村子里长大的”把出生地/童年短活动提升为成长地；模型审校漏检。该组不计作门禁通过。新增确定性成长/童年居住守卫：没有明确成长期证言，不接受这类更强断言；标题兜底也必须再次通过确定性守卫。不是靠重复抽样掩盖漏检，也不以三次模型结果宣称通用事实准确率。
